# AI & Machine Learning Laboratory

A collection of 14 hands-on laboratory experiments covering the fundamentals of Artificial Intelligence (AI) and Machine Learning (ML), using Python, Scikit-learn, TensorFlow, and Raspberry Pi.

## About This Repository

This repository documents practical exercises completed as part of AI and Machine Learning laboratory work. It progresses from Python programming and data analysis to machine learning algorithms, neural networks, computer vision, and edge AI applications.

## Laboratory Experiments

| Lab | Topic |
|---|---|
| Lab 01 | Python for AI |
| Lab 02 | NumPy |
| Lab 03 | Pandas and Matplotlib |
| Lab 04 | Raspberry Pi Setup |
| Lab 05 | Physical Computing with Raspberry Pi |
| Lab 06 | AI Search Algorithms |
| Lab 07 | Regression with Scikit-learn |
| Lab 08 | Regression on Raspberry Pi |
| Lab 09 | Logistic Regression and K-Nearest Neighbors (KNN) |
| Lab 10 | Logistic Regression and KNN on Raspberry Pi |
| Lab 11 | Artificial Neural Networks |
| Lab 12 | Decision Trees, Random Forests, and Support Vector Machines (SVM) |
| Lab 13 | Edge Machine Learning with Raspberry Pi |
| Lab 14 | Convolutional Neural Networks (CNN), Mask Detection, and Face Recognition |

## Technologies and Tools

- **Programming:** Python
- **Data Analysis:** NumPy, Pandas, Matplotlib
- **Machine Learning:** Scikit-learn
- **Deep Learning:** TensorFlow
- **Hardware Platform:** Raspberry Pi
- **Applications:** Regression, classification, neural networks, computer vision, and edge AI

## Learning Objectives

- Practice Python programming for AI and ML.
- Understand data manipulation and visualization.
- Implement and explore fundamental machine learning algorithms.
- Develop an understanding of neural networks and computer vision.
- Explore machine learning applications on Raspberry Pi and edge devices.

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/EngBushraNazir/AI-ML-Laboratory.git
   ```

2. Open the repository folder:

   ```bash
   cd AI-ML-Laboratory
   ```

3. Navigate to the laboratory folder you want to explore.

4. Install the required libraries for that experiment and follow any instructions provided in its folder.

**Note:** Dependencies may vary between experiments. Check the individual laboratory files before running the code.
