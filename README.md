# AI & Machine Learning Laboratory

A collection of 14 hands-on laboratory experiments covering the fundamentals of Artificial Intelligence (AI) and Machine Learning (ML), using Python, Scikit-learn, TensorFlow, and Raspberry Pi.

## About This Repository

This repository documents practical exercises completed as part of AI and Machine Learning laboratory work. It progresses from Python programming and data analysis to machine learning algorithms, neural networks, computer vision, and edge AI applications.
